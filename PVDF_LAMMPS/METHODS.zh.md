# PVDF 多结构/多元序列：计算指标、参数与判据

本文件是可执行协议的解释。默认参数只是起点，不是经过你体系验证的生产参数。没有具体结构和力场时，无法保证任一候选的绝对性质精度。

## A. 结构–性能研究的对照设计

先分开三类问题：

1. **纯排列效应**：固定各单体数、DP/分子量、端基、支化度，改变交替/随机/嵌段/梯度/指定序列。同组成同 DP 时分子质量一致；不同组成时不能同时假定同 DP 与同分子量。
2. **组成效应**：改变共聚单体比例；应明确固定 DP 还是固定 Mn，另把质量/链长差异作为协变量。
3. **形态介导效应**：一组在匹配密度/晶型/结晶度下比较局部化学作用；另一组采用一致制备历史，让形态自然变化，比较整体材料响应。不可既把结晶度固定又声称得到序列通过结晶度产生的完整影响。

每组记录：单体序列、二元/三元片段频率、连续段长度、端基、分子量分布、头头/尾尾缺陷、链数、构型生成 seed、温度、密度、晶区/非晶比例、溶剂与盐配方、表面晶面/缺陷/羟基化、力场版本及文件哈希。

`batch/generate.py` 计算 DP、单体摩尔分数、异种二元片段比例、连续段均值/最大值、二元/三元片段分布。它不生成聚合物、不赋参；示例中的 A/B 仅占位。以 >=3 个独立结构/packing 实现及速度种子为初始设计，增加到误差足以判断候选差异；仅对同一个冻结形态换 3 个速度种子不能充分衡量形态差异。

推荐用同一批 matched recipes 做比较，不把 dry/interfacial/slurry/electrolyte 数据混作一种状态。候选很多时先做便宜结构/吸附筛选，再对不确定或有代表性的候选做自由能、长时间流变和 QM。最终采用多目标比较，不预设“粘附最大即最好”。

## B. 全局单位、平衡与起始参数

| 参数 | 模板默认值 | 解释及检查 |
|---|---:|---|
| units | real | Å、fs、kcal/mol、atm、e、g/cm³ |
| T / P | 300 K / 1 atm | 替换成实验；不同候选同工况 |
| dtfs | 0.5 fs | 柔性全原子起点；做 NVE 能量漂移与目标量敏感性检查，再考虑约束与更大步长 |
| Tdamp / Pdamp | 100 / 1000 fs | 起点，检查温控/压控是否改变动力学 |
| neq / nprod | 200000 / 2000000 步 | 默认 0.1 ns / 1 ns，**仅演示协议，通常不足以证明长链平衡或粘度/输运收敛** |
| 静电 | PPPM 示例 1e-5 | 力误差容限，需与 1e-6 等比较；不是整体性质误差 |
| neighbor | skin 2 Å，每步检查 | 应按实际密度/速度和 GPU 性能调整 |

基本流程：建模/去重叠 → 最小化 → 合适温度下结构松弛 → bulk NPT 密度/盒形验证 → 在确定参考体积的 NVT/NVE 或规定加载条件下生产。bulk 模板只做各向同性 NPT；各向异性晶体/定向半结晶材料应评估 `aniso` 或受约束盒形平衡，而不是盲目沿用。不要为了“平衡”自动熔化已指定的半结晶形态。

长链平衡检查包括 Rg、末端距离、主链取向/二面角、链内距离随轮廓长度关系、链/段松弛与缠结，不只有温度和密度。根据性质需要延长到相关松弛时间以上。NPT 最后一个瞬时体积不一定代表平均体积；生产用确定的参考体积并在 NVT 再平衡。

## C. 界面粘附

| 具体目标 | 计算与定义 | 文件/输出 | 参数与判据 |
|---|---|---|---|
| 表面结构、覆盖 | 表面/聚合物 z 密度、接触原子比例、局部构型、表面层间距/粗糙度 | adhesion/equilibrium：trajectory、polymer_z_density、interaction | 同晶面/表面处理/聚合物覆盖量；按几何暴露层定义表面，不能默认任意 Cu/Al 原子都是表面 |
| 固定几何交叉作用 | Ucross=U_pair+U_kspace；Wcross=-Ucross/A | interaction.dat；cross_scan.dat | 只适合可分解的非反应势、无跨界共价键；多体势和电荷响应需另定义能量分解 |
| 吸附能验证 | Eads=E_complex-E_surface-E_polymer，分别明确 frozen 或 relaxed reference | cross_scan 与同构型 DFT；独立参考系统能量 | 单低聚物用 eV/分子；薄膜用 J/m²；不能把多界面总能量除以一个面积 |
| 湿态脱附自由能 | COM z−固定 anchor COM；U_bias=K(z−z0)²/2；WHAM 得 PMF(z) | adhesion/umbrella、window.dat、postprocess wham | 每窗独立初态；先窗口平衡；逐窗重叠/慢构象收敛；K 和中心实际记录 |
| 法向/切向强度 | T=-Fgrip/A，峰值牵引；Wpull=∫T dδ | pull_normal / pull_shear；traction.dat | 默认 speed=1e-4 Å/fs=10 m/s，仅数值起点；至少改变数倍速率、膜厚和加载层厚度 |

slab 采用 `p p f` + PPPM slab correction；真实真空/边界空间也要足够，避免拉伸时撞 z 边界。保持总电荷中性，检查侧向面积和真空厚度收敛。基底底层 anchor 固定，其余原子可动；不将整片基底完全冻结后推论基底形变。`grip` 必须是预先选定的 polymer 原子 ID，与 anchor 不重叠；力统计前不对 grip 施加 setforce 清零。

能量换算：1 kcal/mol/Å² = 0.6947695457 J/m²；1 kcal/mol/Å³ = 6947.695457 MPa。Wcross 是冻结构型相互作用密度，不是有限温度粘附自由能，也不包含聚合物变形耗散。group/group 不包含跨组 bonded 能。

umbrella 默认 K=2 kcal/mol/Å²、中心由用户指定。300 K 下粗估窗口热涨落宽度 sqrt(kBT/K)≈0.55 Å，因此可以先试约0.3–0.5 Å间距，但实际接触与构象势垒会改变所需窗口。对一个小的完整链做脱附易于定义；整片聚合物 COM 自由能与膜内变形会耦合。所有窗口的侧向、取向和其他约束需一致，并计入自由能定义。WHAM 输出的是 1D PMF，不自动等于标准吸附自由能，更不能无条件除以面积。PMF 无平台、反向窗口不一致或构象未混合时不能宣布收敛。

建议比较 dry、residual-solvent、electrolyte-wet 三种匹配界面；浸液后模型的电解液添加量是固定组成，不自动等于平衡吸液量。

## D. 机械性能

| 指标 | 算法 | 对照与限度 |
|---|---|---|
| 密度 ρ | bulk NPT，平衡段质量/体积统计 | 同温压；真空 slab 的全盒 density 没有薄膜密度意义 |
| 晶型/结晶度 | 主链 torsion、连续 T/G 序列、局部取向/堆积和结构因子联合分析 | postprocess dihedrals 仅输出构象比例；晶相识别须用本体系晶体参考校准，不提供“trans比例=β晶相”的伪标签 |
| 链统计 | Rg²、Re²、回转张量、主链 bond P2(z)、分段统计 | chain_stats.in 和 structure.py；按每链/同DP/化学片段比较，检查 image flags |
| 杨氏模量/泊松比 | x单轴拉伸、y/z侧向压控；斜率 E=dσx/dεx，νxy=-dεy/dεx | strain_rate=1e-7 fs^-1=1e8 s^-1、maxstrain=0.05，仅起点；线性区自行选择并做速率收敛 |
| 完整弹性 Cij | 从同一参考盒做6类应变的±ε独立NVT松弛/平均；Cij=[σi(+εj)-σi(-εj)]/(2εj) | Voigt xx yy zz yz xz xy；剪切使用工程γ；默认ε=0.005，比较0.0025/0.005/0.01等验证线性与噪声 |
| 缠结 | 线性链 PPA/Z1+ 得原始路径长度、约束数和指定定义下Ne | structure.py可导出主链交换数据；不是Z1原生输入；需按所选工具转换/运行；Rg或接触数不能代替缠结数 |
| 塑化 | 同配方基准比较 E(w)/E(0)、ρ、链/段松弛、界面分离功变化 | 固定实际含液量和温度；不得用纯PVDF与高含液样品直接归因于序列 |

有限温度弹性支路适于采样时间内保持固体结构的材料；液态长期松弛的剪切刚度不等于高频玻璃态模量。输出 C 的反对称部分和对称部分特征值，不能用对称化掩盖未收敛或不稳定。固定键力场可描述滑移/空穴/链拔出，但不能描述真实共价断链；大变形“断裂应变”解释需限于该模型。

## E. 加工流变

| 指标 | 方法与脚本 | 必要判据 |
|---|---|---|
| 溶液密度、链尺寸 | 同温压同质量分数 NPT，再rheology/structure | 多序列同溶剂配比/链浓度；记录Rg分布而不只均值 |
| 平衡剪切粘度 | η=V/(kBT)∫<δPxy(0)δPxy(t)>dt；gk模式输出瞬时压力 | 恒定盒，不能用NPT轨迹套常体积公式；积分平台、块误差、相关窗口敏感性 |
| 剪切变稀 | nemd: fix deform remap v + nvt/sllod；η=-<Pxy>/γdot | 多速率点；丢启动段；积累足够应变到稳态；检查流速剖面与剪切温度 |
| 混合焓 | 独立NPT的混合物及同温压纯组分参考，按物质的量/质量一致归一得到ΔHmix | 用equilibrate的enthalpy；纯组分相态、PVDF链长/端基匹配；单个group/group交叉能不是混合自由能 |
| 混溶自由能 | 自由能积分、经校准的化学势/Flory–Huggins模型、足够尺度的相分离分析 | 本包不自动输出χ或相图；ΔHmix不能替代ΔGmix，短MD未分相不证明混溶 |
| 颗粒吸附 | rheology/adsorption输出polymer–particles能与接触比例；界面umbrella补PMF | 默认4 Å只作示例，按距离分布确定；完整链吸附比例/驻留可另按molecule-ID聚合；不能将原子接触比例称为吸附链比例 |

默认GK采样每10步，0.5fs步长对应5fs；corr_points=10000对应约50ps相关窗口，不宣称覆盖高分子终端松弛。对于高粘长链，更长窗口/生产长度或经动力学校准的粗粒化模型可能必要。Python工具对每块去均值并多时间原点相关，但统计块长度仍需足够大。不同非平稳应力不能靠去均值“修复”。

默认SLLOD剪切1e-7 fs^-1；须跑到稳态并做更低/更高速率。溶液粘度不能替代完整浆料粘度；实际浆料需要活性颗粒和导电网络，原子模型尺度不足时先匹配吸附/流变再粗粒化。

## F. 离子输运

| 指标 | 方法 | 参数与限度 |
|---|---|---|
| 溶剂化 | Li–polymer donor、Li–solvent donor、Li–anion donor RDF；CN=4πρ∫r²g(r)dr | rdf.dat输出每对g与累计配位；按每类第一谷选择截断，不能全部固定3 Å作结论 |
| 配位交换/离子关联 | 按完整阴离子/溶剂mol-ID统计接触；连续/间歇接触相关函数 | association.py；距离cutoff与采样频率敏感；donor配位数不等于阴离子个数；无直接接触不自动判成SSIP |
| 自扩散 | 多时间原点MSD；D=(1/6)dMSD/dt | Li位点、完整阴离子COM；确定扩散区log–log斜率近1；未进入扩散区不输出“已收敛D” |
| 集体电导率 | M(t)=Σqiri(t)；σ=[1/(6VkBT)]d<\|M(t+τ)-M(t)\|²>/dτ | 对全体系所有部分电荷求和，包含离子交叉关联；严格中性、恒定盒、无净流、正确unwrapped坐标 |
| NE近似/关联影响 | σNE=(1/VkBT)ΣNiqi²Di；比较σ/σNE | NE用相同模型有效电荷；电荷缩放力场需明确，不能把形式电荷NE与缩放电荷集体结果混比 |

LAMMPS compute msd输出单原点诊断，最终使用Python多原点结果。阴离子若由多个原子组成，不能把所有原子当独立载流子计算NE。不要分别扣除Li和阴离子子群COM，否则删掉真实集体运动；后处理只扣除整个体系COM作为共同参照。离子迁移数涉及选定参照系/Onsager系数，本包不把D_Li/(D_Li+D_anion)当真实迁移数。

`analysis/postprocess.py transport` 需要全体系轨迹；将电中性极性聚合物的所有部分电荷计入M是允许的，短时束缚极化贡献必须在长时间扩散斜率中排除。生产期间若出现反应、电荷重分配、原子数变化，此固定电荷后处理不适用。当前实现读入所保留的离子坐标/电荷矩到内存，长轨迹用stride或拆分独立统计块；不要为节省文件而丢掉必要的长时/快配位信息。

公式单位换算：MSD斜率Å²/fs乘1e-5/6得m²/s；电荷矩斜率e²Å²/fs乘e²×1e25/(6 V_A3 kBT)得S/m；S/m除100为S/cm。

## G. 氧化反应

见05_oxidation/QM_WORKFLOW.zh.md，明确VIP、AIP、氧化自由能、空穴/自旋定位、反应能与能垒。LAMMPS仅做构型采样或已验证ReaxFF下的反应势能计算。没有DFT/反应数据时，氧化性能列留空；不输出假电位。

## H. 收敛、排名与实验

每项输出除均值外保留独立模型/速度实现的分布和误差条；分别比较采样误差、链长/盒尺寸/加载速率误差、力场模型误差。高R²并不能证明扩散区或弹性区选择正确。

建议特征矩阵：序列组成/二三元片段 → 主链构象与溶剂化 → 结晶/缠结/吸附机制 → W、E、η、D、σ与氧化量。回归验证按序列家族/独立结构划分，不能把同一条轨迹的相邻帧随机拆成训练和测试而造成信息泄漏。候选差异小于不确定性时标为无法区分。

实验对照：同表面处理的界面/剥离、同含液量拉伸/DMA、同配方流变、NMR扩散/阻抗以及一致电化学条件和产物分析。MD界面牵引与宏观剥离之间仍需几何、孔隙和耗散的桥接。
